\texttt{ps} takes one snapshot of the process table and exits, so its output can
be piped, filtered and saved; \texttt{top} is an interactive monitor that
repaints every few seconds, sorted by CPU usage, and adds system-wide summaries
\texttt{ps} never prints --- load average, task counts by state, memory totals.
So \texttt{ps} answers ``what is running right now, in a form I can process'',
and \texttt{top} answers ``what is this machine doing, and what is consuming
it''.
