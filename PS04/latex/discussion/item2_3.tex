As observed in item 1, compiling with \texttt{-no-pie} pins the global
\texttt{x} to a fixed address (\texttt{0x404018}), whereas the default PIE
build subjects it to ASLR. The local \texttt{x} in \texttt{main()} resides on
the stack, where both the address and the uninitialised value vary on every run
regardless of the PIE setting.
