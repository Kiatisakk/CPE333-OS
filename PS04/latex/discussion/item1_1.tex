Declaring \texttt{y} as \texttt{static} allocates it in the initialised data
segment rather than the stack, giving it static storage duration. The
initialisation (\texttt{= 5}) occurs only once, at program startup. Subsequent
iterations execute only \texttt{y++}, producing the values 6, 7 and 8 at an
invariant address. (\texttt{auto} on \texttt{x} is the default for local
variables and has no effect.)
