\texttt{extern int x;} \emph{declares} \texttt{x} without defining it: it tells
the compiler that a variable of that name and type exists somewhere and that
this function should use it, rather than creating a new one. The definition is
the file-scope \texttt{int x = 20;}, which is what actually reserves storage.

Both functions therefore name the same object, so both print 20 and both print
the same address. Here the \texttt{extern} declarations are redundant --- the
file-scope definition is already visible to both functions --- but they make the
intent explicit, and in a real program they are how one translation unit reaches
a variable defined in another.
