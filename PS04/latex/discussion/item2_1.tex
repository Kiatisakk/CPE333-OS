\texttt{extern int x;} declares \texttt{x} without defining it, instructing the
compiler to reference the existing file-scope definition (\texttt{int x = 20;}).
Both functions therefore reference the same object in the data segment, printing
identical values (20) and addresses. While redundant here within a single file,
\texttt{extern} makes shared linkage explicit and is how one translation unit
reaches a variable defined in another.
