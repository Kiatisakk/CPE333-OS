% Discussion for lab1_item3 -- never overwritten by make_latex.py.

With symbolic links, deleting either level~1 or the source breaks level~2. With
hard links, level~2 survives both deletions.

A symbolic link is resolved name by name (\texttt{l2\_sym.txt -> l1\_sym.txt ->
src\_s.txt}), so losing any name in the chain breaks it, even when the file at
the end still exists. A hard link made from level~1 is not a link to level~1:
it is a third name for the same inode (link count~3), and each deletion only
lowers the count.
