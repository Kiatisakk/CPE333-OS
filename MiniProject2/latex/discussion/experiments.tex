Three programs (Appendix~A) serve as targets. Each stops itself with
\texttt{SIGSTOP} after every stage, so each reading is taken while the
process is not running; \texttt{kill -CONT} lets it continue. Monitoring
starts with the first \texttt{pfcount} call, after the program has started
up, so the ``since monitoring started'' figures count only the faults caused
by the stage under test. At every stop, \texttt{run\_all.sh} also compares the
module's figures with \texttt{/proc}: the fault totals with
\texttt{/proc/<pid>/stat}, the region list with \texttt{/proc/<pid>/maps}, the
virtual size with \texttt{VmSize} and the RSS with \texttt{smaps\_rollup}.
They agreed every time (Appendix~B).
