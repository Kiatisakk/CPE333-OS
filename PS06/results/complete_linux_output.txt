SWAP - CREATE AND ENABLE 1 GIB FILE
$ sudo fallocate -l 1G /swapfile_ps6
$ sudo chmod 600 /swapfile_ps6
$ sudo mkswap /swapfile_ps6
Setting up swapspace version 1, size = 1024 MiB (1073737728 bytes)
no label, UUID=68ca62eb-08e5-4ec5-9993-45e18cf9a378
$ sudo swapon /swapfile_ps6

SWAP - AFTER INCREASE
$ swapon --show
NAME          TYPE       SIZE USED PRIO
/dev/sdc      partition    3G   0B   -2
/swapfile_ps6 file      1024M   0B   -3
